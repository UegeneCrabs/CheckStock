# Исправление GAS-выгрузки WB FBS

Замените содержимое файлов `Helpers.gs`, `WbApi.gs` и `Export.gs` в Google
Apps Script одноимёнными файлами из этой папки. Остальные GAS-файлы менять
не требуется.

Исправления:

- 30-дневные окна больше не пропускают последний день;
- пагинация продолжается по `next` из ответа WB, а не по размеру страницы;
- 19-значный курсор `next` сохраняется как строка и не округляется JavaScript;
- заказы дедуплицируются по `id`;
- `Артикул` и `Артикул WB (nmId)` заполняются значением `nmId`;
- колонка `Заказано` формируется самим GAS и очищается вместе с отчётом,
  поэтому после старой выгрузки не остаются пустые строки со значением `1`.

После замены повторно выгрузите период 01.08.2026–31.08.2026 для TRIS.
