Правила выгрузки и состав данных

Для Яндекс Маркета, Ozon и Wildberries задаются три отдельных файла Google Таблиц. В каждом файле — проекты площадки, настройки остатков, FBS-заказов и FBO в пути до и от клиента. У каждой площадки своё расписание. Чекбокс «Автозапуск» включает соответствующую выгрузку. Кнопками внутри площадки можно отдельно выгрузить остатки, FBS-заказы или FBO в пути. Для каждого товара добавляется проект; одинаковые артикулы разных проектов остаются отдельными строками.

В остатках J — остаток перемещений между ФФ, K — остаток проведённых поставок на склады МП. Оба значения читаются из складского учёта БД. ТОТАЛ в F = ФФ + FBS + FBO + в пути между ФФ + в пути на склады МП (G:K). Непроведённые поставки не входят в K.

Количество в пути рассчитывается как отправлено минус принято и отменено. Если учтённых товаров в пути нет, записывается 0. Выгрузка читает сохранённый учёт: она не загружает поставки из API и не проводит их автоматически. Проведение поставок доступно в разделе поставок FBO.

В остатках колонка A содержит КЛЮЧ в формате «ПРОЕКТ БАРКОД», например «RIMILI 1234567890». B — ПРОЕКТ, C:E — артикул, штрихкод и название. Нераспределённые остатки выгружаются по каждому ФФ в отдельные колонки, начиная с L: «ДОСТУПНО ФФ ДЛЯ РАСПРЕДЕЛЕНИЯ — название ФФ». Колонки идут по алфавиту; при отсутствии остатка записывается 0. Общая сумма остаётся в G. Разбивка раскрывает эту сумму и повторно в ТОТАЛ не добавляется. Перед каждой выгрузкой лист остатков полностью очищается от старых значений и формул, объединения снимаются. Для FBS-заказов задайте столбец количества. В существующем листе находятся ARTICLE и «Проект» в одной строке; выбранный столбец очищается со следующей строки до последней заполненной строки, затем количество записывается по совпадению артикула и проекта. Товары без заказов получают 0. Для FBO в пути задайте отдельное название листа и два столбца: к клиенту и от клиента. Данные FBO запрашиваются по API заново при каждом запуске, параллельно по кабинетам. Сопоставление и очистка работают так же, как для FBS. Отсутствующее количество — 0; при ошибке API запись по площадке не начинается. Лист остатков должен быть отдельным. FBS и FBO одной площадки могут использовать общий лист с разными столбцами. В разных файлах названия листов могут совпадать.

Отправку на МП нужно отражать отгрузкой с ФФ, чтобы отправленный товар не оставался одновременно в остатке ФФ и в пути. Сама выгрузка остатки в базе не меняет.

На каждом выгруженном листе стоков в A1:B1 записывается дата и время выгрузки по Москве. В первой строке листа остатков от F (ТОТАЛ) до последней колонки записываются формулы суммы по товарам, например =SUM(F3:F). Шапка остаётся в строке 2, товары — с третьей строки. Старое содержимое первой строки остатков заменяется автоматически. Это время записи в Google Таблицу, а не обновления остатков в API. В FBS-выгрузке изменяется только выбранный столбец под шапкой; остальные колонки, заголовки и строки выше сохраняются.
