Выгрузка данных в таблицу

Загружайте остатки, заказы и отчёты через меню таблицы или по расписанию. Скрипт получает все страницы выбранного отчёта и обновляет отдельный лист.

  1. Создайте ключ на вкладке «API-ключи», например «Google Таблицы — остатки».
  2. В Google Таблице откройте Расширения → Apps Script.
  3. Скачайте скрипт выгрузки, вставьте его в редактор Apps Script и сохраните.
  4. Откройте Настройки проекта → Свойства скрипта и добавьте параметры из таблицы ниже.
  5. Перезагрузите Google Таблицу. Выберите Данные сайта → Обновить отчёт и разрешите выполнение скрипта.
СвойствоЗначение
API_BASE_URLПубличный HTTPS-адрес сайта, без пути. Адрес localhost или 127.0.0.1 из Google недоступен.
API_TOKENПерсональный API-ключ, без слова Bearer.
API_STOREКод магазина из метода /api/agent/v1/stores.
API_REPORTНапример stocks, orders или profit. По умолчанию stocks.
API_PARAMSНеобязательно: фильтры в JSON. Например {"date_from":"2026-09-24","date_to":"2026-09-24"} для заказов. Для остатков можно {"view":"summary"}.

Результат появится на листе API_название-отчёта. При обновлении содержимое этого листа заменяется. В первых строках указаны время загрузки и предупреждения источников.

Настраивайте скрипт в таблице с доверенными редакторами: они имеют доступ к связанному проекту Apps Script и его свойствам. Для отдельной таблицы используйте отдельный ключ.

Обновление по расписанию

В Apps Script откройте «Триггеры», добавьте триггер для функции refreshCheckStock, выберите источник «По времени» и нужный интервал. Даты в API_PARAMS остаются фиксированными, пока вы их не измените.

При истечении срока ключа создайте новый и замените API_TOKEN. Если загрузка не завершилась, прежние данные останутся на листе. Для больших отчётов сузьте период или добавьте фильтр товара.
