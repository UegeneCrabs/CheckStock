Подключить к ChatGPT

  1. Откройте редактор своего GPT.
  2. Вставьте готовую инструкцию в поле «Инструкции» вашего GPT.
    Открыть инструкцию
  3. Добавьте 5 готовых фраз для начала разговора в поле «Фразы для начала разговора» вашего GPT — каждую отдельной строкой.
  4. Нажмите «Создать новое действие».
  5. В Authentication выберите API Key → Bearer и вставьте свой ключ.
  6. Вставьте схему.
    Открыть схему
  7. Сохраните GPT с доступом только для себя.

Если поделиться этим GPT, другие пользователи смогут обращаться к данным с вашим ключом. Для общего GPT компании нужен отдельный вход каждого сотрудника.
