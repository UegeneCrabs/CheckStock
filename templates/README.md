# Шаблоны страниц

| Папка | Страницы |
|---|---|
| `layout` | Общая оболочка и шапка сайта. |
| `auth` | Вход и отсутствие доступа. |
| `account` | Профиль пользователя. |
| `stock` | Остатки, TOTAL, операции, поставки и отчёты. |
| `economics/wb` | Экономика WB, настройки и отчёты. |
| `economics/yandex` | Настройки экономики ЯМ. |
| `economics/shared` | Общая таблица и карточка товара для WB/ЯМ. |
| `admin` | Список пользователей и редактор пользователя. |
| `integrations` | Интеграции и выгрузка в Google Таблицы. |
| `agents` | Подключение ИИ-агентов. |

Шаблоны читаются через `app.web.templating` по пути относительно этой папки, например `stock/total.html`. Используется `string.Template` с переменными `$name`.

Крупные части подключаются комментарием `<!-- include: stock/forms/upload.html -->`. Переменные `$name` подставляются после включения частей. Формы складских операций находятся в `stock/forms`, поля калькулятора WB — в `economics/wb/calculator-fields.html`. CSS-ссылки из страницы автоматически переносятся в `<head>` общей оболочки.

В `client` лежит разметка, которую заполняет JavaScript. Файл соответствует имени скрипта: `static/stock/inbound-supplies.js` использует `stock/client/inbound-supplies.html`. Внутри файла именованные фрагменты ограничены комментариями:

```html
<!-- template: item -->
<span>{{name}}</span>{{{content}}}
<!-- endtemplate -->
```

`{{name}}` экранирует текст и значения атрибутов. `{{{content}}}` предназначен для готовой разметки другого шаблона или уже проверенных значений. Вывод: `CheckStockUI.render('stock/inbound-supplies/item', {name, content})`. Сервер отправляет JSON-каталог только для подключённых скриптов; отсутствующий фрагмент или параметр вызывает явную ошибку. Общие фрагменты находятся в `common/client/ui.html`.

В HTML нет исполняемых встроенных скриптов. Блоки `script type="application/json"` содержат только данные страницы. Динамические размеры и CSS-переменные, вычисляемые по данным таблицы, остаются параметрами отображения; постоянные правила находятся в CSS.
