Как рассчитывается выкуп Яндекс Маркета

Обновляется каждые 4 часа за выбранное число завершённых дней, без сегодняшнего. Новый период применяется при следующей загрузке.

Если статистики нет или выкуп равен 0, используется процент по умолчанию. При пустом поле подстановка не применяется.

Параметры расчёта и цели отчёта
Целевая ценаДРР с учётом выкупа и целевой ROI для выбранного кабинета. Применяются в отчёте «Целевая цена» ЯМ.
Целевой ROI по коду товара

ROI по коду имеет приоритет над общим ROI. Индивидуальные цели товара имеют приоритет над настройками кабинета.

Экономика и расходы

FBY и FBS используют общие параметры и тарифы. Общие значения применяются ко всему кабинету. Для отдельного товара можно задать свои параметры. Комиссия компании единая для FBY и FBS и вычитается от цены продавца.

Пустое поле и кнопка ↺ возвращают значение источника. Ноль — явное значение без расходов. Сохраняются только изменённые поля. Тарифы и график выплат загружаются из фактических настроек магазина на Яндекс Маркете. Перевод платежа (Экваринг1) задаётся отдельно для кабинета: по умолчанию 1,6% от цены продавца. Приём платежа (Экваиринг 2) загружается из API в рублях.
