Общие проценты для расчёта акций

Минимальный и максимальный проценты задают границы эластичного бустинга. Между ценами процент меняется линейно. Статичный процент действует для остальных акций, когда текущая цена не выше цены для бустинга. Пустое поле — процент не задан.

Параметры расчёта Ozon
Целевая ценаЦель по ДРР с учётом выкупа и целевой ROI для выбранного кабинета. Используются в отчёте «Целевая цена» Ozon.
Целевой ROI по коду товара

ROI по коду имеет приоритет над общим ROI. Пустой ROI по коду использует общий. Индивидуальные цели товара имеют приоритет над настройками кабинета.

Процент выкупа30 завершённых дней без сегодня · обновление каждые 4 часа

(Получено − клиентские возвраты) / (получено + отменено) × 100 по заказам FBO и FBS за последние 30 завершённых дней. Товары в пути исключены. Период фиксирован для всех кабинетов Ozon. При отсутствии статистики или выкупе 0% используется выкуп по умолчанию, если он задан. Выкуп для логистики считается отдельно по оплаченным доставкам за те же 30 дней.

Расходы и налогиСтавки для расчёта юнит-экономики

Прочее нераспределённое задаётся для каждого кабинета: цена селлера × процент / 100 вычитается из чистой прибыли. Начальное значение — 0%. Для остальных ставок пустое поле означает, что ставка не задана. Ноль — явное отсутствие расхода. Значения используются в калькуляторе, марже и целевой цене Ozon.

Почасовой прогноз OzonСобственные коэффициенты D кабинета · МСК

Прогноз товарооборота = сегодняшний товарооборот × D текущего часа по Москве. Пустое поле — коэффициент не задан, прогноз и отклонения показываются как «—». Ноль сохраняется как заданное значение. Коэффициенты других площадок не используются.
