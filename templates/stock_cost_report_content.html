Как считается ЗЦ Для новых операций фиксируется закупочная цена из 1С на момент проведения × количество. Старые операции без снимка используют текущую ЗЦ и отдельно помечают товары без цены. Продажи FBS Основная цифра: остаток FBS перед периодом + перемещения на FBS − остаток FBS в конце периода. Продажи из API маркетплейса показаны рядом только для сверки.
