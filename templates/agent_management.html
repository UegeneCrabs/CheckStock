Только чтение данных
Вы работаете локально. Ключи и API можно проверить здесь, но ChatGPT не сможет обратиться к этому компьютеру напрямую. Для подключения нужен доступный из интернета HTTPS-адрес.

Создать подключение

Каждому личному GPT — отдельный ключ. Его права совпадают с вашими правами на сайте.

Ключ готов

Скопируйте его сейчас: повторно показать ключ нельзя. Вставьте его в настройках Action, не в переписке с GPT.

Подключить к ChatGPT

  1. Откройте редактор своего GPT и добавьте Action.
  2. Вставьте описание API.
    Открыть схему
  3. В Authentication выберите API Key → Bearer и вставьте свой ключ.
  4. Сохраните GPT с доступом только для себя.

Если поделиться этим GPT, другие пользователи смогут обращаться к данным с вашим ключом. Для общего GPT компании нужен отдельный вход каждого сотрудника.
