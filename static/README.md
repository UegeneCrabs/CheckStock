# Файлы интерфейса

| Папка | Назначение |
|---|---|
| `common` | Общая тема, навигация, таблицы, модальные окна и копирование идентификаторов. |
| `account` | Профиль пользователя и его доступы. |
| `stock` | Остатки, TOTAL, поставки, карточка товара, подсказки и отчёты. |
| `stock/forms` | Загрузка ФФ, перемещение и отгрузка; общий запуск и проверка доступности редактора. |
| `economics/shared` | Таблица и карточка экономики WB/ЯМ; общие формулы калькулятора WB. |
| `economics/wb` | Настройки кабинета, отчёт прибыли и целевой цены WB. |
| `economics/yandex` | Дополнения и настройки экономики ЯМ. |
| `admin` | Управление пользователями. |
| `integrations` | Подключения и загрузки. |
| `agents` | API-ключи, инструкция подключения и иллюстрация. |
| `images` | Общие изображения и favicon. |

URL файла: `/static/<папка>/<файл>`. Ссылки находятся в `templates` и `app/web`. CSS и JavaScript одного раздела хранятся рядом.

`common/app.css` задаёт порядок общих стилей и компонентов через `@import`. Базовые правила находятся в `base.css`, формы и складские страницы — в `stock`, элементы выбора, фильтрации и модальных окон — в отдельных файлах `common`. `preferences.css` содержит адаптивное оформление; `header.css` — шапку; `account/profile.css` — профиль.

`common/ui.js` предоставляет экранирование, копирование и вывод клиентских HTML-шаблонов. Разметка находится в соседнем по смыслу разделе `templates/**/client`, а не в строках JavaScript. Скрипты страницы магазина подключаются в `templates/stock/store.html`, рандомайзера — в `templates/stock/randomizer.html`.

При добавлении ресурса используйте имя его функции в разделе: `total`, `supplies`, `target-price`. Общие компоненты WB и ЯМ размещайте в `economics/shared`. Порядок подключения CSS значим для каскада; при переносе правил проверяйте обычный и узкий экран.
