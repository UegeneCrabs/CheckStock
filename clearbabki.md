# Расчёт чистой прибыли

## Итоговая формула

**Чистая прибыль =**

**Чистая выручка**  
− **Закупочная цена**  
− **Фулфилмент**  
− **((Комиссия команды) × Цена без СПП)**  
− **НДС**  
− **УСН или ОСНО**

Цена покупателя — цена клиента с СПП. Если её нет, брать цену без СПП.
---

# 1. Чистая выручка

**Чистая выручка =**

Цена розничная  
− Эквайринг  
− Доставка с учётом возвратов  
− (Оборачиваемость × Хранение WB)  
− (Цена розничная × Процент WB)  
− (Цена розничная × ДРР)

---

## 1.1. Цена розничная - ГОТОВО----------------------------

**Источник:** API WB

Просто цена без СПП.

---

## 1.2. Эквайринг

**Формула:**

`Цена без СПП × процент эквайринга`

- Дефолтный процент: **3,8%** - ГОТОВО----------------------------
- Настраивается отдельно для каждого магазина - ГОТОВО----------------------------
- Процент можно менять вручную - ГОТОВО----------------------------

---

## 1.3. Доставка с учётом возвратов - ГОТОВО----------------------------

**Формула:**

`(Доставка WB × % выкупа + (за 1 возврат + Доставка WB × 2) × (1 - % выкупа)) + Стоимость платной приёмки`

### 1.3.1. Доставка WB - ГОТОВО----------------------------

- По дефолту: **0**
- Можно менять
- Ручной параметр

### 1.3.2. % выкупа - ГОТОВО----------------------------

- По дефолту: **0**
- Можно менять
- Ручной параметр

### 1.3.3. За 1 возврат - ГОТОВО----------------------------

- По дефолту: **0**
- Можно менять
- Ручной параметр

### 1.3.4. Стоимость платной приёмки - ГОТОВО----------------------------

**Формула:**

`ЕСЛИ(Объём 1 товара для личного кабинета, Л. < 1; 0; (1,7 + ОКРУГЛВВЕРХ(Объём 1 товара для личного кабинета, Л. - 1; 0) × 1,7) × кф приёмки)`

#### 1.3.4.1. Объём 1 товара для личного кабинета - ГОТОВО----------------------------

- По дефолту: **0**
- Можно менять
- Ручной параметр

#### 1.3.4.2. КФ приёмки - ГОТОВО----------------------------

- По дефолту: **0**
- Можно менять
- Ручной параметр

## 1.4. Оборачиваемость - ГОТОВО----------------------------

Зависит от **КОДА ТОВАРА**:

| Код товара | Оборачиваемость |
|---|---:|
| A | 30 |
| B | 28 |
| Остальные | 21 |

### 1.4.1. КОД ТОВАРА - ГОТОВО----------------------------

Источник — лист **ФАКТ ПРОДАЖ** каждого магазина.

Поля:

- **Код ABC** — колонка с кодом товара
- **ARTICLE** — артикул
- **BARCODE** — баркод

## 1.5. Хранение WB - ГОТОВО----------------------------

- По дефолту: **0**
- Можно менять
- Ручной параметр
- Единица измерения: **рублей за штуку**

---

## 1.6. Процент WB - ГОТОВО----------------------------

**Формула:**

`Комиссия СУ + Доп. тарифы WB`

### 1.6.1. Доп. тарифы WB - ГОТОВО----------------------------

- По дефолту: **0%**
- Можно менять
- Ручной параметр

### 1.6.2. Комиссия СУ - ГОТОВО----------------------------

Источник:

[Таблица с комиссиями WB](https://docs.google.com/spreadsheets/d/1ff-qWxrDth7Qi4hp5lWmb4IX0Nw8UvqGG6LBmQS4_Fc/edit?gid=1234800956#gid=1234800956)

- Колонка **A** — категория товара

> Если категория не найдена — расчёт помечается как требующий настройки комиссии.

## 1.7. ДРР - ГОТОВО----------------------------

**Формула:**

`Расходы на рекламу / Заказали на сумму`

Для расчёта по дефолту используется период **7 дней от текущего дня**.

- Расходы на рекламу — API WB
- Заказы — API WB

> Если заказов за период = 0 и расходы на рекламу > 0 — ДРР считать **100%**.

# 4. Для клиента с WB кошельком - ГОТОВО----------------------------

**Источник:** API WB

Цена с СПП.

Для расчёта необходимо:

1. Взять заказы за последнюю неделю.
2. Получить цены заказов.
3. Найти среднюю цену.
4. Пересчитывать значение каждый день.

Если за **7 дней** нет ни одного заказа:

- расширить период до **14 дней**;
- если необходимо — до **30 дней**.

# 5. Комиссия команды - ГОТОВО----------------------------

- Формула: **Цена без СПП × процент комиссии команды**
- По дефолту: **4%**
- Можно менять
- Ручной параметр

---

# 6. Налоги

Для всех магазинов:

- **НДС = Цена покупателя × (% НДС / (100 + % НДС))**
- **УСН = (Цена покупателя − НДС) × % УСН / 100**
- текущее значение старого поля «Налоги» переносится в процент НДС;
- проценты НДС и УСН задаются вручную в параметрах кабинета.

Для магазина **GOGOL** доступен переключатель **УСН / ОСНО**:

- в режиме УСН вычитаются НДС и УСН;
- в режиме ОСНО вычитаются НДС и ОСНО;
- **ОСНО = Цена покупателя × % ОСНО / 100**.
