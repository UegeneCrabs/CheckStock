# Общие комментарии в юнит-экономике

Колонка «Комментарии» на страницах WB, Яндекс Маркета и Ozon открывает один
текст на площадку, магазин и точный артикул. Любой активный пользователь с
доступом к товару может прочитать и изменить этот текст. Для Ozon применяется
тот же переключатель доступности, что и для страницы юнит-экономики.

Комментарий сохраняется по Enter или при выходе из поля. Shift+Enter добавляет
строку. Максимум — 480 символов. Пустой текст очищает комментарий. Последнее
успешное сохранение заменяет предыдущий текст. Таблица
`unit_economics_product_comments` не содержит владельца или ревизий.
Пустая запись сохраняется, чтобы старый браузерный текст не восстановил
удалённый комментарий.

При загрузке страницы браузер переносит доступные ему старые комментарии
этой площадки из локального хранилища. Перенос касается и страницы Яндекс
Маркета. Если общий текст отличается, он сохраняется, а старая версия остаётся
только в локальном хранилище исходного браузера. Текст браузера, который ещё не
открывал обновлённую страницу, недоступен для переноса с сервера.
Отчёт Яндекс Маркета `goods-feedback` используется для рейтинга и числа отзывов.

Маршруты `/api/unit-economics-1c/product-comments/{marketplace}`:

| Метод | Назначение |
| --- | --- |
| GET | Читает текущие комментарии к доступным магазинам площадки. |
| PUT | Проверяет товар в каталоге и заменяет текст по ключу из `store_slug` и `article`. |
| POST `/import` | Принимает до 100 старых комментариев и добавляет только отсутствующие записи. |

Значения `marketplace` — `WB`, `YANDEX MARKET` и `OZON`. Новая таблица
создаётся при штатной инициализации схемы SQLite или PostgreSQL.
