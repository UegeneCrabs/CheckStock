# Категории и комиссии Яндекс Маркета

Выгрузка `yandex_category_commissions_sync` проверяет все товары каталога каждого
подключённого кабинета по понедельникам в 04:00 МСК. Пропущенная проверка выполняется
через минуту после запуска приложения; сохранённая отметка не позволяет повторять
её при каждом перезапуске. В разделе фоновых выгрузок есть отдельная кнопка ручного
обновления и выбор кабинетов.

Источники API:

- `POST /v2/categories/tree` — полное дерево категорий;
- `POST /v2/businesses/{businessId}/offer-mappings` — категория, цена и габариты товара;
- `POST /v2/tariffs/calculate` — комиссия размещения `FEE` для действующей кампании.

Для товара сохраняется вся ветка от корня до листовой категории. В калькулятор
тарифов передаётся именно листовая категория: проценты родителей не складываются.
Комиссии запрашиваются отдельно для действующих кампаний FBY и FBS с фактическими
настройками кабинета. Комиссия размещения не включает логистику, приём и перевод
платежей. Итоговое начисление за заказ может отличаться от справочного расчёта API.

Данные хранятся в `yandex_economics_sources`: `category`,
`category_commission:FBY`, `category_commission:FBS`. Запись по кабинету атомарная;
ручные настройки, закупки и остатки не изменяются. Последняя проверка хранится
отдельной записью с источником `yandex_category_commissions_sync` и пустым артикулом.

Если в API нет цены, размеров или веса, сохраняется причина отсутствия комиссии.
При сетевой ошибке прежняя комиссия остаётся в записи с отметкой ошибки, но не
подставляется как актуальная. При разных комиссиях кампаний сохраняются все
варианты; без выбранной кампании неоднозначный процент в расчёт не подставляется.

Еженедельный процент применяется только для той же категории, габаритов и цены
либо явно разрешённого API ценового диапазона. Срок актуальности — семь суток.
Свежий полный расчёт тарифа имеет приоритет перед недельной комиссией; ручные
замены пользователя имеют приоритет перед обоими источниками. Остальные компоненты
тарифа сохраняют свои прежние правила обновления и актуальности.

Полная ветка категории и даты проверок видны в параметрах товара калькулятора YM.

Документация: [дерево категорий](https://yandex.ru/dev/market/partner-api/doc/ru/reference/categories/getCategoriesTree),
[расчёт стоимости услуг](https://yandex.ru/dev/market/partner-api/doc/ru/reference/tariffs/calculateTariffs).
