# API аналитики CheckStock

API расположен под `/api/agent/v1`. Личный Bearer-ключ связан с существующим пользователем CheckStock. При каждом запросе проверяются срок действия ключа и активность его владельца. Все активные пользователи видят настроенные магазины и реализованные отчёты; автоматического ограничения по ФИО менеджера нет. Подробности — в [контракте учётных записей](authentication.md).

## Подключение

Страница `/ai-agents` содержит управление ключами, схему API и готовую инструкцию подключения. Текст инструкции хранится в `static/agents/agent-instructions.txt`, а схема формируется приложением по адресу `/api/agent/v1/openapi.json`.

Для внешнего подключения задайте `CHECKSTOCK_AGENT_PUBLIC_URL` — публичный HTTPS-адрес приложения. Развёртывание описано в [agent-api-deployment.md](agent-api-deployment.md).

## Доступные отчёты

Сначала получите `capabilities`, `stores` и `data-status`: они определяют доступные пользователю магазины, площадки, отчёты и состояние данных. Параметры конкретного отчёта смотрите в актуальной схеме API.

| Метод GET | Содержание |
|---|---|
| `products`, `product-details` | Каталог, поиск и карточка товара. |
| `product-newness`, `product-reputation`, `product-tags` | Новизна, отзывы и классификация товаров. |
| `advertising` | Реклама и её показатели. |
| `stocks`, `stock-value` | Текущие остатки и стоимость по известной ЗЦ. |
| `stock-operations`, `supplies` | Складские операции и планы поставок. |
| `prices`, `costs` | Цены, себестоимость и расходы. |
| `profit`, `loss-products` | Показатели отчёта прибыли и товары с убытком. |
| `profit-calculator` | Сохранённые входные данные и результаты калькулятора. |
| `current-economics` | Текущая экономика из таблицы сайта. |
| `target-prices` | Целевые цены и предупреждения исходных расчётов. |

`article-stores` помогает определить доступный магазин по артикулу. Поддержку площадок проверяйте через `capabilities`; она различается между отчётами.

Наличие крайних дат в `data-status` не доказывает полноту периода. Пропущенные значения, неполные расчёты и предупреждения источника должны сохраняться в ответе пользователю. Отчёт прибыли, текущая экономика и калькулятор имеют разные источники и периоды; их показатели нельзя автоматически подменять друг другом.

Отчёты читают доступные снимки и данные приложения. Получение отчёта не является разрешением изменять остатки, заказы, цены или права пользователя.

## Ключи из командной строки

Из корня проекта на нужной машине:

```shell
python -m scripts.ops.agent_key issue --user-id 7 --days 30 --output secrets/employee-7-key.txt
python -m scripts.ops.agent_key list
python -m scripts.ops.agent_key revoke ID_КЛЮЧА
```

Файл нового ключа предназначен только его владельцу. В хранилище приложения сохраняется хеш. Отзыв ключа и отключение пользователя прекращают доступ; все активные пользователи имеют одинаковую видимость данных.


## Общая инструкция ИИ-агентов

Полная версия `static/agents/agent-instructions-full.txt` — основной источник правил и подробных примеров. В ней четыре раздела с заголовками `## Общие правила`, `## Wildberries`, `## Яндекс Маркет`, `## Ozon`. Вкладка `/ai-agents/instructions` показывает их отдельно через `agents/instruction-card.html`. Общие правила применяются вместе с правилами нужной площадки. Копирования и скачивания в этом справочнике нет. MCP читает весь тот же файл при initialize и через getAnalyticsInstructions, добавляя указания для MCP: подключение остаётся единым, выбор раздела на сайте его не ограничивает.

Компактная версия `static/agents/agent-instructions.txt` предназначена для поля «Инструкции» GPT с Actions. Ссылки и копирование на `/ai-agents/gpt` используют только её. Лимит 8 000 проверяется только для компактной версии с учётом UTF-16 и CRLF. В уже созданном GPT текст обновляется вручную после выкладки; для MCP переподключите коннектор/начните новый чат, чтобы клиент получил актуальные правила.

Версии редактируются согласованно: при изменении правил обновляйте полную и её компактное изложение. Автоматического сокращения нет. Полная версия не ограничена лимитом редактора GPT; сокращённая отсылает к схеме за подробностями полей.

`static/agents/instruction-sections.js` разбирает четыре обязательных раздела полного текста без отдельной копии правил. `instructions.js` загружает файл без кеша и переключает разделы в справочнике; при ошибке загрузки или структуры переключение недоступно и показано сообщение. На существующей странице GPT Actions тот же загрузчик продолжает использовать адрес компактной инструкции из data-instruction-url кнопки. Прежнее копирование Actions, ключей и схемы через `clipboard.js` сохранено. Навигация — `agents/navigation.html`.

### Каталог по площадкам

`/ai-agents/catalog` предлагает «Все площадки», Wildberries, Яндекс Маркет и Ozon. Отдельный раздел показывает методы, для которых одновременно есть поддержка площадки и доступная пользователю область в scopes. Поиск учитывает название, назначение и описания полей выбранной площадки. При смене площадки открытый метод сохраняется, если остаётся доступен и соответствует поиску; иначе карточка предлагает выбрать другой метод. Счётчик показывает число доступных или найденных методов.

Карточка отдельной площадки использует её marketplace_guides: точные поля ответа, подписи, единицы, ограничения и описание. Общие поля ответа и параметры остаются справочником существующего API; для marketplace явно показаны значение выбранной площадки и фактическое умолчание API, если оно задано схемой. Переключатель документации не подставляет параметры в реальные запросы. Режим «Все площадки» сохраняет сравнительную таблицу WB/Яндекс/Ozon и обозначения поддерживаемых площадок в списке методов.

Реализация представления — `static/agents/catalog.js`, `catalog-comparison.js`, `catalog.css`, общие переключатели — `marketplaces.css`. HTTP-контракты, инструменты единого `/mcp`, ключи, права, расчёты и БД не меняются.

Контракт новых методов СПП: [почасовая и дневная история](agent-spp-history.md).
Контракт рейтинга склейки WB: [сравнение периодов и дневная история](agent-wb-rating.md). Оба метода доступны через прежнюю схему и единое MCP-подключение только для WB; в существующем MCP нужно обновить список инструментов.
Проверки интерфейса: `node --test tests/agent_instructions.cjs` и
`python -m unittest discover -s tests -p test_agent_management.py -v`.

### Термины в общей инструкции ИИ

Рейтинг WB в отчёте и его динамика относятся к склейке товаров. Агент обязан подписывать показатель «Рейтинг склейки WB», даже при запросе одного артикула. Рейтинг отдельного товара без склейки может отличаться; он не хранится в БД и недоступен для ответа. При таком запросе агент объясняет ограничение, не подменяет индивидуальный рейтинг рейтингом склейки и не делает вывод о доказанном снижении индивидуальной оценки. Правило включено в полную MCP-инструкцию и компактную GPT Actions-инструкцию; к Яндексу и Ozon автоматически не применяется.

«Стандартные условия» означают сценарий без ИУ; ИУ — индивидуальные условия, также «специальные условия», «спецусловия» и «спец условия». Запросы комиссий, логистики и прибыли на стандартных условиях нельзя подменять данными с ИУ. Метод StandardCosts возвращает прибыль/ROI и состояние; недоступные через API статьи расходов агент должен обозначать как ограничение.

Слова «прибыль», «чистая прибыль», «маржа», «ROI» и «РОИ» в запросах команды относятся к расчётным показателям сайта. В ответах прибыль называется расчётной (потенциальной), ROI — расчётным. Сайт не подтверждает фактическую чистую прибыль. Само употребление этих синонимов не требует уточнения.

Термины согласованы в полной и компактной версиях. В существующем GPT с Actions инструкцию необходимо скопировать заново.

Площадка сохраняется в рамках текущего разговора: явный выбор в новом запросе имеет приоритет, иначе используется последняя однозначно выбранная площадка. После вопросов про WB продолжение «а остатки?» относится к WB; те же правила действуют для Яндекса и Ozon. Переход к другой площадке требует явного запроса; данные площадок не смешиваются без просьбы, а отсутствие данных не служит поводом для переключения. Запрос сравнения или всех площадок не меняет единственный выбранный контекст; при неоднозначности агент уточняет. WB по умолчанию используется только при отсутствии выбора и контекста. Это правило не обещает сохранение предпочтения между разными чатами.

«Соинвест», «со-инвест» и «соинвестирование» означают СПП Ozon — скидку покупателя относительно цены продавца. Только если площадка не выбрана ни в запросе, ни в разговоре, этот термин выбирает Ozon вместо стандартного WB; при конфликте с явно указанной или ранее выбранной другой площадкой агент уточняет противоречие. Показатель доступен как `CurrentEconomics.spp_percent` и `OzonAnalyzer.spp`. Его нельзя подменять СПП WB или дополнительной скидкой по Ozon Карте. Новые методы и поля для синонима не добавляются; неизвестное значение остаётся неизвестным. Правило включено в общие инструкции MCP и GPT Actions, а описание показателя — в каталог Ozon.

### Сохранение правил при сокращении инструкции

Общая инструкция сохраняет правила новинок: подтверждённое отсутствие поступления и остатка означает «Ожидает поступления», а неизвестный остаток не равен нулю. Дата запуска не выводится из sales_days. Анализ включает этапы первого дня, дней 2–4 и первых 14 дней, обоснование уровней риска и ограничение: наличие на ФФ не доказывает доступность FBO/FBS.

Чтобы сохранить лимит поля GPT, перечисления полей сокращены в пользу схемы инструментов. Правила СПП, стандартных/индивидуальных условий и потенциальной прибыли сохранены. Проверка сравнивает полную инструкцию с передачей через MCP; это не проверка поведения самой модели.
