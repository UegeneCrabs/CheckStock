# Ручные выгрузки

В разделе «API и выгрузки» каждая задача имеет кнопку «Выгрузить вручную».
Доступ, как и к настройкам интеграций, только у суперадминистратора.

Кнопка вызывает `POST /api/admin/integrations/sync-jobs/{name}/run`.
Ответ `202` содержит идентификатор запуска. Работа продолжается в фоне:
HTTP-запрос и открытая страница не нужны для её завершения.
Страница получает статусы через `GET /api/admin/integrations/sync-jobs` каждые
5 секунд, включая после повторного открытия. Результат и ошибки сохраняются
в обычном журнале `sync_job_runs` с признаком `manual`.

Ручной запуск игнорирует выключатель автовыгрузки, включая отключённый фоновый
режим приложения, но сохраняет выбор магазинов и маркетплейсов. Если не выбрана
ни одна цель, сервер отвечает `409`. Сами настройки при запуске не меняются.

`app/jobs/manual.py` использует обработчики расписания. Исключения нужны для
явного запуска сейчас: Google Таблицы вызывают `run_store`, справочники —
`sync_all(force=True)`, цены WB — `price_sync.sync_stores`, ключи WB —
`refresh_token_info`. Даты закрытия дня, формулы, правила новинок и сохранения
данных остаются внутри существующих загрузчиков. FTP сохраняет прежний пересчёт
следующего запуска; остальные ручные запуски не сдвигают расписание.

`sync_tracking` удерживает блокировку задачи до завершения. Для PostgreSQL
используется [advisory lock](https://www.postgresql.org/docs/current/functions-admin.html#FUNCTIONS-ADVISORY-LOCKS), общий между контейнерами приложения и сборщика.
Для SQLite используется файловая блокировка в каталоге БД, общая для локальных
процессов. Блокировка освобождается при завершении процесса или соединения.
Ошибки запуска и частичные ошибки загрузчиков записываются в историю.

Цены витрины ЯМ используют существующие `Browser` и `run_once` из
`scripts/parsers/parse_yandex_storefront_prices.py`. Ручной браузер работает без окна,
с отдельным профилем `data/yandex-storefront/manual`; расписание и профиль
постоянного сборщика не меняются. Общая блокировка в БД у этого сборщика
предотвращает одновременную обработку цен, в том числе между контейнерами.
Локально нужны `requirements-parser.txt` и Google Chrome, как для сборщика.
В Docker зависимости Chromium включены в образ приложения, а профиль ручного
браузера сохраняется в отдельном томе `yandex-manual-data`.

Кнопка запускает одну задачу. Добавление кнопок само по себе не выполняет
загрузки и не отправляет данные в Google Таблицы или на FTP.
