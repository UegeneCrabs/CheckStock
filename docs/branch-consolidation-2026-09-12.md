## Решения при объединении

Снимок старой ветки метрик ЯМ сопоставлен с коммитом `2d26cdc`: его функциональность уже перенесена в текущую ветку, где дополнительно появились новизна товаров, полнота периодов и последующие доработки экономики. Для сохранения оригинальных коммитов использован merge со стратегией `ours`: текущие реализации сохранены, старые коммиты стали предками итоговой ветки. Полное сравнение сохранено в `.tmp/merge-all-20260912/yandex-vs-integrated.patch`.

В складской ветке разрешены восемь конфликтов. Сохранены новые права доступа и удаление прежних разделов; их устаревшие тесты не возвращались. Для TOTAL выбраны согласованные правила: одна строка на артикул, сумма остатков между магазинами и площадками, колонка магазинов после ЗЦ, исключение полностью нулевых товаров.

Совмещены оба источника цены: общая таблица 1С и отдельные значения ЯМ. Если у карточки есть оба значения, выбирается максимальное, затем максимум рассчитывается по всем доступным карточкам артикула. Ноль остаётся заполненной ценой; отсутствие цены не удаляет товар с остатком.

После завершения merge обычный push текущей ветки отправит её код и всех достижимых родителей, включая оригинальные коммиты обеих объединённых веток:

```sh
git push origin codex/yandex-active-assortment
```

Force push и отдельная отправка каждой исходной ветки не требуются.
