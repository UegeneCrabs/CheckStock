# Дополнительные источники WB для ИИ-агентов

В API `/api/agent/v1/` добавлены шесть GET-методов. Всего схема содержит
30 операций аналитики. Авторизация прежняя: персональный Bearer-ключ;
MCP автоматически получает методы из той же схемы. Запросы не запускают
синхронизацию и не изменяют данные.

| Путь | operationId | Основные параметры |
| --- | --- | --- |
| `/stock-history` | `getAnalyticsStockHistory` | store, date_from, date_to; article, scheme, warehouse |
| `/orders` | `getAnalyticsOrders` | store, date_from, date_to; article, order_id, status, scheme, manager |
| `/inbound-supplies` | `getAnalyticsInboundSupplies` | store; article, supply_id, status, warehouse |
| `/supply-arrivals` | `getAnalyticsSupplyArrivals` | store; date_from, date_to, status, warehouse |
| `/stock-cost-report` | `getAnalyticsStockCostReport` | store, date_from, date_to; cost_view |
| `/economics-history` | `getAnalyticsEconomicsHistory` | article; store |

`marketplace=WB`. При точном article можно не указывать store: действует
существующий поиск магазина с проверкой неоднозначности. В остальных случаях
store обязателен. Пагинация: limit 1–100, offset, next_offset; список полей
сортировки/фильтрации отражён в схеме и capabilities. Периоды включают обе даты,
максимум 90 дней. Будущие даты допустимы только для расписания поступлений.

## Источники и ограничения

- StockHistory читает сохранённые дневные снимки маркетплейса и ФФ. Нет снимка —
  неизвестное значение. Транзит не включён. warehouse фильтрует ФФ: исторических
  снимков по отдельным складам WB в этом источнике нет.
- Orders читает нормализованный реестр sales_order_lines по дате создания
  заказа (МСК). Возвращает текущие сохранённые статусы и строки заказа;
  исходный JSON и данные покупателей не выдаются. Фильтр менеджера и ограничения
  доступа к его товарам применяются до пагинации.
- InboundSupplies читает кэш сервиса поставок FBO. Одна строка — товар в поставке;
  поставка с неизвестным составом обозначена items_missing. status фильтрует
  нормализованный stage. sources содержит время последнего успеха, stale и has_error.
- SupplyArrivals читает общий реестр магазина из Google Sheets. Доступ требуется
  ко всем площадкам магазина, поскольку строки не имеют marketplace. Фильтр дат
  относится к фактическому приходу, строки без даты исключаются. Ссылки на файлы
  и внутренний адрес таблицы в ответ не включаются.
- StockCostReport использует расчёт страницы «Движение и ЗЦ», её права и разрешение
  STOCK_OPERATIONS_VIEW. cost_view выбирает summary, deliveries, transfers,
  shipments, fbs_transfers, fbs_sales или fbs_actual_sales. Межплощадочные детали
  скрыты, если недоступна одна из сторон. Имена сотрудников не выдаются.
  Формульные продажи FBS не равны фактическим. Проверять available в
  context.reconciliation; missing_units означает неполную стоимостную оценку.
  Сводка не включает вложенный полный список товаров: для него используются
  постраничные представления.
- EconomicsHistory возвращает последние 21 день графика конкретного товара,
  используя существующий расчёт сайта. Текущий день неполный, null и
  margin_complete сохраняются. Произвольный исторический период не поддерживается.

## Установка

Развернуть изменённую ветку обычным способом. Миграции БД и новые зависимости
не нужны. В GPT Actions заново импортировать `/api/agent/v1/openapi.json`
и обновить инструкцию из `static/agents/agent-instructions.txt`. MCP получает
новые инструменты автоматически при обновлении списка инструментов клиентом.
Наличие метода не подтверждает наличие свежих данных: проверить источники
на рабочем сервере после установки.
