# Пять запросов менеджера

| Запрос | Источник и условия |
| --- | --- |
| Сток без вчерашних заказов | `stocks` без транзита + `profit.orders_count` за вчера. Отсутствующая строка не равна нулю. Если нужны именно выкупы, использовать соответствующий показатель и учитывать даты его источника. |
| Падение ТО к тем же дням прошлой недели | Два запроса `profit.orders_amount` за равные завершённые периоды. Почасовое сравнение текущего дня с прошлой неделей не реализовано. |
| ДРР 0–10% и отрицательный ROI | `profit.drr` и `profit.roi` из одного отчёта за один период. Не включать неизвестный/неполный ROI. |
| Сток и падение показов | `stocks` + `profit.impressions` отдельно за каждый из двух дней. По уточнению пользователя это колонка «Показы» блока «Реклама» отчёта «Юниточная прибыль». Это рекламные показы, не общая органическая видимость и не переходы в карточку. |
| Активная кампания и CTR <5% | Новый `advertising-campaigns`, `active_only=true&ctr_below=5`. Одна строка — товар в кампании, CTR только этой кампании. |

Для всех запросов: разрешённые магазины и товары менеджера, все страницы,
название из базы, сортировка товаров по ТО заказов за общий период.
Пустая или неполная выборка не доказывает отсутствие подходящих товаров.

## Кампании

При штатной синхронизации рекламы сохраняются ежедневные показатели по кампании
из уже загружаемого `adv/v3/fullstats`. Дополнительно читается
`api/advert/v2/adverts` партиями до 50 ID для статуса и текущего состава товаров.
Статус 9 означает активную кампанию. Документация:
[WB API — Продвижение](https://dev.wildberries.ru/openapi/promotion).

Новая таблица `wb_advertising_campaign_snapshot` создаётся при обычном `init_db`.
Снимок содержит только последний полностью загруженный период синхронизации
(по умолчанию семь дней, включая сегодняшний). История старого агрегата по товару
не позволяет восстановить CTR по кампаниям.

Ответ содержит время наблюдения статуса. Снимок старше 24 часов, ошибка обновления
или запрос вне загруженного периода дают `context.available=false`. Отсутствующая
статистика и нулевые показы дают неизвестный CTR; такие строки не проходят
фильтр `ctr_below`. Статус не считается историческим или доступным в реальном времени.
Ошибка загрузки метаданных кампаний не отменяет существующий отчёт рекламы по товарам.

## Выпуск

1. Развернуть ветку и перезапустить приложение с обычной инициализацией БД.
2. Выполнить штатное обновление рекламы нужных магазинов (нужны права токена WB
   на продвижение). Проверить `context.available` нового метода.
3. Обновить схему Action из `/api/agent/v1/openapi.json` и инструкцию
   из `/static/agents/agent-instructions.txt`, сохранить GPT.
4. Проверить пять запросов на данных сервера и сверить с отчётом сайта.

Доступность токенов WB и свежесть данных проверяются на рабочем сервере.
