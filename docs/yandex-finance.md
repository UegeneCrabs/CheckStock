# Финансовые отчёты Яндекс Маркета

Пункт «Финансовые отчёты → Яндекс» в обеих шапках CheckStock открывает [внешний сервис](https://153.76.164.196) в новой вкладке. Вход выполняется в самом сервисе.

Встроенная страница, её API и задание загрузки удалены. При инициализации схемы [миграция](retired-report-tables.md) удаляет восемь старых таблиц `finance_yandex_*`; текущая ORM-схема их не создаёт. Данные заказов, остатков и юнит-экономики Яндекс Маркета по-прежнему хранятся в своих таблицах.

[Архивное техническое задание на встроенный отчёт](yandex-finance-spec.md).
