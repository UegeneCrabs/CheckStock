# Независимое развёртывание RBE

Ветка сайта: **deployment/rbe**. Не сливать с master и не обновлять сервер из master.
Ветка содержит весь CheckStock, поскольку импортёр RBE использует общие модули.
Действующий сайт: https://153.76.164.196.

Изменения готовить в отдельном клоне ветки deployment/rbe. После проверки:

```sh
git push origin HEAD:refs/heads/deployment/rbe
```

На сервере `/usr/local/sbin/rbe-update --check` проверяет доступную версию.
`/usr/local/sbin/rbe-update` устанавливает её: проверяет ветку и чистоту кода,
разрешает только fast-forward, останавливает RBE и его фоновые процессы,
создаёт резервную копию, обновляет код, запускает службу и проверяет HTTPS.
При ошибке возвращает предыдущий код. Данные автоматически не откатываются.
Обновление запускается вручную после проверки изменений, не при каждом push.

Изменения зависимостей блокируют обычное обновление: сначала нужно подготовить
и проверить окружение. Миграции базы также требуют отдельного плана и проверки;
проверка `/health` не заменяет функциональные проверки после релиза.

Код: `/opt/rbe/code`; данные/секреты: `/opt/rbe/shared`; настройки: `/etc/rbe.env`.
Базы, ключи и пользователи не входят в Git. Резервные копии: `/opt/rbe/backups`.
Скрипт установлен отдельно от дерева Git; изменения самого update.sh необходимо
проверить и установить в `/usr/local/sbin/rbe-update` отдельно.
