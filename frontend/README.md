# React-интерфейс CheckStock

Приложение на React, TypeScript и Vite включает вход, выход, шапку «РАКЕТА» и
заглушки разделов. В рабочей среде React открывается на `ui.rocketbm.ru`, а
основной сайт FastAPI — на `rocketbm.ru`.

## Локальный запуск

1. Задайте `CHECKSTOCK_UI_ORIGIN=http://localhost:5189` в корневом `.env` и
   запустите FastAPI как обычно на порту `8000`.
2. В каталоге `frontend/` выполните `npm ci`, затем `npm run dev`.
3. Откройте [localhost:5189](http://localhost:5189) и войдите под учётной записью
   локального CheckStock.

Vite проксирует `/api/auth/` и `/static/` к `http://127.0.0.1:8000`.
Для другого локального адреса backend задайте `CHECKSTOCK_UI_BACKEND` в окружении
Vite. При занятом порте `5189` запуск завершается с ошибкой.

- `npm run lint` проверяет код через Oxlint.
- `npm run build` проверяет TypeScript и собирает `dist/`.
- `npm run preview` открывает готовую сборку на том же порту с тем же прокси.
  Перед его запуском остановите Vite dev.

Каталог маршрутов и пунктов шапки находится в `src/pages.ts`. Общий компонент
`Header` показывает одно меню на всех страницах. Для разделов площадки он
берёт из маршрута цвет и название маркетплейса, включая мобильную шапку.
Zustand хранит в памяти статус сессии и данные профиля. Cookie хранит браузер,
а сессию проверяет FastAPI. [Контракт входа](../docs/authentication.md#сессия-react).
[Настройка поддомена](../docs/releases.md#поддомен-react).
