# Инструкции Codex для CheckStock

- При любой работе в этом репозитории сначала применяй `$checkstock-task-guide` из [SKILL.md](.agents/skills/checkstock-task-guide/SKILL.md). В каждом новом чате перед изменением кода прочитай и соблюдай раздел «Обязательные правила разработки Ozon» с учётом его области действия. Если автоматический выбор скилла недоступен, открой этот файл напрямую. Полные правила хранятся в скилле; не дублируй их в других инструкциях.
- При выпуске через GitHub и разборе ошибок деплоя применяй `$checkstock-deploy` из [SKILL.md](.agents/skills/checkstock-deploy/SKILL.md).
- Для вопросов о поведении проекта и новых задачах используй `docs/llm-wiki.md` как карту, а `docs/README.md` — как индекс подробных инструкций. Сверяй важные утверждения с текущим кодом и тестами.
- Если пользователь просит реализовать задачу, после изучения контекста продолжай реализацию и проверку. Не останавливайся на плане, если план не был единственным запросом.
